# بيانات البذر التجريبية

هذا المجلد يحتوي كتالوجاً تجريبياً جاهزاً لتحميله لحظة بناء المشروع، حتى لا تُفحَص الواجهة ولا لوحة التحكم على قاعدة بيانات فارغة. البيانات **وهمية بالكامل**: الأسعار والكميات وأسماء الألوان معقولة للسوق السوري لكنها ليست عروضاً حقيقية.

| الملف | المحتوى |
| --- | --- |
| `catalog.demo.json` | 8 علامات تجارية · 12 فئة · 22 منتجاً بـ 24 متغيّراً · 6 علاقات توافق · سعر صرف تجريبي |

## ما الذي يغطيه هذا الكتالوج عمداً

اختيرت المنتجات لتغطي **كل الحالات الحدّية** في نموذج البيانات، لا لتكون قائمة جميلة:

| الحالة | المنتج الذي يمثّلها |
| --- | --- |
| منتج بمتغيّرين مختلفَي المصدر ورمز النسخة | آيفون 15 برو ماكس (`ZA/A` خليجي بشريحتين، و`LL/A` أمريكي بـ eSIM فقط) |
| جهاز مستعمل بدرجتين مختلفتين | آيفون 13 (`USED_A`, بطارية 89%) وآيفون 11 (`USED_B`, بطارية 84%) |
| جهاز مجدَّد بكفالة أطول | آيفون 12 مجدَّد (6 أشهر كفالة محل) |
| متغيّران يختلفان باللون فقط | جالكسي A16 (أسود وأزرق بنفس السعر) |
| هاتف بلا ذاكرة ولا شبكة حديثة | نوكيا 110 (`storage_gb = 0`، شبكة 2G) |
| ملحق بلا كفالة إطلاقاً | جراب آيفون (`warranty_type = NONE`, `warranty_months = 0`) |
| منتج بلا حقول جوال أصلاً | البطارية المحمولة والشاحن الشمسي والكابل (`storage_gb`, `sim_type`, `network_gen` = `null`) |
| مخزون نادر يفعّل قاعدة الندرة | جالكسي S23 مستعمل (`demo_stock = 1`) وآيفون 15 برو ماكس أمريكي (`2`) |
| توافق ملحق مع أجهزة متعددة | الكابل متوافق مع ثلاثة موديلات آيفون |

إن مرّت هذه الاثنتان والعشرون على النظام بلا خطأ، فالنموذج سليم.

## التحميل

```bash
pnpm db:seed --file seed/catalog.demo.json
```

البذر عملية **جامدة (idempotent)**: إعادة تشغيلها تحدّث الصفوف الموجودة بمطابقة `slug` و`sku` ولا تكرّرها. وهي ممنوعة في بيئة الإنتاج إلا بتمرير `--allow-prod` صراحة.

## من وهمي إلى حقيقي

كل صف من هذا الملف يُنشأ بـ `is_demo = true`، وهذه العلامة ليست وسماً شكلياً بل تغيّر سلوك النظام:

| السلوك | المنتج التجريبي |
| --- | --- |
| الظهور في الموقع | يظهر في بيئات التطوير والتجريب فقط |
| فهرس البحث وخريطة الموقع | مستبعَد تماماً في الإنتاج |
| إنشاء طلب عليه | **مرفوض** برمز `DEMO_PRODUCT_NOT_ORDERABLE` |
| الكمية | `demo_stock` رقم عرضي لا يمر بدفتر `inventory_movements` ولا ينشئ `device_units` |
| بوابة الإقلاع | التطبيق يرفض الإقلاع في الإنتاج إن وُجد منتج `is_demo` منشور، ما لم يُفعَّل `DEMO_MODE` |

**التحويل إلى منتج حقيقي** يتم من لوحة التحكم بزر «تحويل إلى منتج حقيقي»، وهو ليس تبديل علامة بل مسار تحقق: يُطلب سعر التكلفة الحقيقي، وإدخال المخزون عبر إيصال استلام فعلي (لا `demo_stock`)، وأرقام IMEI للأجهزة، وصور حقيقية للجهاز نفسه إن كان مستعملاً أو مجدَّداً، ثم تُطبَّق بوابات الجودة المعتادة قبل النشر. التفصيل الكامل في [الفصل 7](../docs/07-catalog.md).

ولحذف كل ما هو تجريبي دفعةً واحدة قبل الإطلاق:

```bash
pnpm db:purge-demo        # يفشل إن كان أي منتج تجريبي مرتبطاً بطلب أو مطالبة
```

## تنبيه
