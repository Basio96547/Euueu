# تشغيل زبير على حاسوبك للتعديل عليه

كلُّ أمرٍ في هذه الصفحة **جُرِّب على نسخةٍ جديدة** من المستودع قبل أن يُكتب: استُنسخ، ونُصِّب، وشُغِّلت اختباراته الثلاثمئة والثلاثة والأربعون، وبُني. فما هنا ليس وصفةً متوقَّعة بل خطواتٌ رأيتُها تعمل.

---

## ١. ما تحتاج تنصيبه (مرّة واحدة)

| البرنامج | النسخة | لماذا |
| --- | --- | --- |
| **Node.js** | ٢٢ فأحدث | المشروع يستعمل `node:test` المدمج، ولا يعمل في نسخةٍ أقدم |
| **pnpm** | ١٠ فأحدث | مدير الحزم الذي بُني به ملفُّ القفل |
| **Git** | أيّ نسخة | لتنزيل المشروع وتتبّع تعديلاتك |

**على ويندوز** — نزّل Node من `nodejs.org` ثم في PowerShell:
```powershell
npm install -g pnpm
```

**على ماك أو لينكس** — بـ Homebrew أو المدير الذي عندك:
```bash
brew install node git
npm install -g pnpm
```

وفي المشروع ملفُّ `.nvmrc` مكتوبٌ فيه `22`: من يستعمل `nvm` يكفيه `nvm use`.

## ٢. تنزيل المشروع

```bash
git clone https://github.com/Basio96547/Euueu.git
cd Euueu
git checkout claude/build-ai-from-scratch-2rnygr
cd zubair
```

> **انتبه للمجلّد.** المستودع فيه مشروعان لا صلة بينهما: **متجر تالي شام** في الجذر (`apps/`, `packages/`)، و**زبير** في مجلّد `zubair/`. وزبير خارج مساحة عمل المتجر، فلا يُنصَّب معه ولا يشترك معه في حزمة. **كلُّ عملك في `zubair/` وحده.**

أو — إن كان الملفّ المضغوط الذي أرسلتُه أسهل — فكّه وادخل مجلّد `zubair`، وتخطَّ خطوة `git clone`.

## ٣. التنصيب والتشغيل

```bash
pnpm install     # مرّة واحدة، نحو نصف دقيقة
pnpm dev         # يطبع العنوان — افتحه
```

يطبع سطراً مثل `Local: http://localhost:5173/`. **والرقم قد يختلف**: إن كان ٥١٧٣ مشغولاً بشيءٍ آخر انتقل إلى ٥١٧٤ فما بعده — فاقرأ العنوان الذي طُبع ولا تفترضه.

وتعديلُ أي ملفٍّ يُحدِّث الصفحة فوراً بلا إعادة تشغيل.

**ولتفتحه من جوالك وأنت تُعدّل على الحاسوب** — الجهازان على نفس شبكة الواي فاي:
```bash
pnpm dev --host
```
يطبع معه سطر `Network:` بعنوانٍ مثل `http://192.168.1.5:5173` — افتحه في متصفّح الجوال. وتعديلُك على الحاسوب يظهر في يدك مباشرة.

## ٤. الأوامر التي ستستعملها

```bash
pnpm test        # ٣٤٣ اختباراً تقيس تعلّمه بالأرقام لا بالانطباع (نحو دقيقة)
pnpm exam        # الامتحان المجمَّد: ٥٨ بنداً على ثلاثة أدمغة جديدة
pnpm ownership   # يطبع جدول الملكية: من يجيب عن أي طلب
pnpm phone       # يفتحه بمقاس جوال ويكتب ثماني لقطات في shots/
pnpm typecheck   # فحص الأنواع بلا بناء — أسرع ما يكشف خطأً
pnpm build       # للنشر: ينتج dist/
```

> **الأمران اللذان يجب أن يمرّا قبل أي تعديل تحفظه:** `pnpm test` و`pnpm exam`. الأول يحرس الفصوص، والثاني يحرس **سلوكه** — وهو الذي يكشف أن جواباً كان صائباً صار محتملاً بلا أن ينكسر شيء.
>
> وإن ارتفعت نسبة الامتحان بتعديلك فاحفظ الأساس الجديد: `pnpm exam --save`.

## ٥. أين تُعدّل

```
zubair/
├── src/brain/core/      الأساس: رياضيات، شبكات، قراءة العربية، حفظ، عتاد
│   ├── ownership.ts     جدول الملكية — لكل طلبٍ فصٌّ مالكٌ واحد
│   ├── review.ts        المراجعة: رتبٌ لا أرقام، وثلاث سلطاتٍ لا رابع
│   ├── reading.ts       القراءة من كتاب: مصدرٌ ثالث لا مساوٍ
│   └── heritage.ts      ما يجيء به: ٧٠٨ كلمة و٤٨٧ حقيقة
├── src/brain/lobes/     الفصوص العشرون، كلُّ فصٍّ ملفٌّ مستقل
├── src/brain/brain.ts   المُوصِل: يمرّر النبضة ولا يفكّر بنفسه
├── src/brain/exam/      الورقة المجمَّدة وتصحيحها
├── src/ui/              الواجهة العربية
└── shots/               لقطات `pnpm phone` (خارج git)
```

**القاعدة الحاكمة**: `brain.ts` لا يحتوي قاعدة تعلّمٍ واحدة ولا عتبة قرار. كلُّ الذكاء في الفصوص. فلو احتجتَ أن تكتب منطقاً معرفياً في المُوصِل، فذاك دليلٌ أن فصّاً ناقص.

**وقاعدةٌ ثانية**: ما يعرفه فصٌّ لا يُعاد كتابته في فصٍّ آخر. كُسِرت ثلاث مرات في هذا المشروع (قائمة الحروف، وأدوات الاستفهام، وأنواع العلاقة)، وفي كل مرّة افترقت النسختان بعد أسابيع وأنتجت عطباً لا يُفهم سببه.

## ٦. لو انكسر شيء

| العَرَض | السبب الغالب |
| --- | --- |
| `pnpm install` يفشل | نسخة Node أقدم من ٢٢ — تحقّق بـ `node -v` |
| `ERR_PNPM_IGNORED_BUILDS: esbuild` ثم فشلُ `pnpm dev` | نسختك من pnpm أحدث من التي بُني بها المشروع، وقد نقلت موضع الإعداد. **صُلح**: `onlyBuiltDependencies` صار في `pnpm-workspace.yaml`. فحدِّث المشروع (`git pull`) — أو إن كنتَ على نسخةٍ قديمة منه: `pnpm approve-builds` ثم اختر `esbuild` |
| `pnpm test` يفشل في `exam.test.ts` | تعديلُك غيّر سلوكه. اقرأ ما طبعه `pnpm exam`: يقول أي بندٍ سقط ولماذا هو في الورقة |
| الاختبارات تمرّ والتطبيق أبيض | افتح طرفية المتصفّح (F12). أو شغّل `pnpm phone` — يطبع كل رسالةٍ فيها |
| «زبير نسي كل شيء» | دماغه في `localStorage` المتصفّح. تبديلُ المنفذ أو المتصفّح يعني دماغاً آخر |

**وللرجوع عن كل تعديلاتك:**
```bash
git checkout -- .
```

## ٧. المحرّر

في المشروع إعداداتٌ جاهزة لـ VS Code (`.vscode/`): مسار TypeScript الصحيح، وخطُّ المئة عمود، وتشغيلٌ بضغطة — و**«اختبار واحد (الملف المفتوح)»** يشغّل ملفَ الاختبار الذي تنظر إليه وحده بدل الثلاثمئة كلِّها. وملفُّ `.editorconfig` يجعل التنسيق واحداً في أي محرّرٍ آخر.
